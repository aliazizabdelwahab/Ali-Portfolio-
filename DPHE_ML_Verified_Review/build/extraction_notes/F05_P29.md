Title: A framework for data regression of heat transfer data using machine learning
Authors: Jose Loyola-Fuentes; Nima Nazemzadeh; Emilio Diaz-Bejarano; Simone Mancin; Francesco Coletti
Year 2024; Applied Thermal Engineering 248, 123043; DOI 10.1016/j.applthermaleng.2024.123043 (OA CC BY-NC-ND). [Old Excel had DOI "not retrieved" - now verified.]
Domain: condensation HTC in microfin tubes (two-phase) - NOT DPHE; literature database 4,333 points from multiple studies.
Framework (6 steps): pre-treatment (outlier removal vs baseline correlation, bounds), feature selection (incl. expert-knowledge features), data-splitting philosophy, training/testing, grid-search hyperparameter tuning, performance assessment (MAE + % points outside +-20%).
Splitting: Scenario 1 random split (interpolation); Scenario 2 grouped by tube geometry (fin-tip diameter d_f): train 13 tubes 2,729 pts (d_f 7.75-8.51 mm), test 40 tubes 1,386 pts outside that range = extrapolation to unseen tubes.
Models: RF (scikit-learn defaults, 100 trees) and DNNs (TensorFlow; 4/3/2 hidden layers: 256-128-64-32, 128-64-32, 64-32; Adam, MAE loss); baseline semi-empirical correlation (not retrained).
Results: interpolation - best ML MAE 535 W/m2K vs correlation 1061; extrapolation (unseen tubes) - ML MAE 1819 vs correlation 1111 -> correlation better out of domain. Expert-knowledge features (dimensionless/physics) improved accuracy.
Relevance: direct evidence that random splits overstate generalisation and that ML loses to physics correlations when extrapolating; supports grouped validation + correlation baseline + physics features.
Tier 3 (methodological framework). High methodological value.
