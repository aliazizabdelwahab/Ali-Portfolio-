Title: Inter-Material Transfer Learning for Accelerated Nanofluid Heat Transfer Prediction: A Machine Learning Approach for Energy Systems
Authors: Soumaya Hadj Salah; Aymen Ochi; Sonia Bezi
Year 2026; Energy Science & Engineering 14:4316-4332 (issue 9); DOI 10.1002/ese3.70580 (OA CC BY)
HX: 2D axisymmetric laminar pipe flow (D 0.01 m, L 0.5 m, constant wall T) - NOT DPHE; OpenFOAM chtMultiRegionSimpleFoam.
Data: CFD; 200 Latin-hypercube simulations Al2O3/water (phi 0.5-5%, Re 1000-2000, Tw 305-330 K) + 20 independent hybrid Al2O3-TiO2 (50:50) simulations (hybrid properties via effective volume fraction mixture rules). CFD vs Pak-Cho water MAPE <8%.
Inputs (3): phi, Re, Tw. Output: Nu.
Pipeline: 80/20 split BEFORE preprocessing; 5-fold CV grid search on training only (n_est 50-200, lr 0.01-0.1, depth 3-7) -> 100 trees, lr 0.1, depth 5, reg_alpha 0.1, reg_lambda 1; stratified 10-fold CV check (R2 0.9946+-0.0022, RMSE 0.0506). Explicit data-leakage prevention table (Table 7). Python 3.10, scikit-learn 1.3, XGBoost 2.0, SHAP 0.43; seed 42; code on GitHub.
Model comparison (test): XGBoost R2 0.996 RMSE 0.045; GB 0.994/0.052; RF 0.992/0.061; ANN 0.989/0.071; SVR 0.975/0.112.
Transfer learning: fine-tune on 20 hybrid points -> R2 0.980 (95% CI 0.951-0.988 bootstrap) vs 0.761 from scratch (text also says 0.895 - inconsistent).
UQ: quantile regression XGBoost (5/50/95%) 91% coverage of 90% PI; bootstrap ensemble (100 models) PIW 1.46%, coverage only 72.5% (overconfident) - authors acknowledge.
Active learning (retrospective): R2 0.98 with 40 vs 200 samples.
OOD: Re extended to 2500 (transitional with laminar solver) - "reasonable accuracy" (qualitative).
XAI: SHAP (Re 63.4%, phi 22.9%, Tw 13.7%), PDP, causal graph (consistency check only).
Critical: CFD only, laminar, single-phase mixture-rule properties (hybrid NF behaviour is assumed, not measured) -> "hybrid" knowledge is model-imposed; internal inconsistencies (0.895 vs 0.761; coverage statements); RMSE units not stated (Nu ~8 -> RMSE 0.045 ~0.5%).
Strengths: best validation hygiene in the set (split-before-preprocessing, CV on train only, leakage table, seeds, code), explicit UQ with calibration check, transfer learning mono->hybrid, active learning.
Relevance: high methodological relevance (small-data hybrid NF, UQ, leakage control); data source not experimental.
Tier 2. Supporting benchmark (validation/UQ methodology).
