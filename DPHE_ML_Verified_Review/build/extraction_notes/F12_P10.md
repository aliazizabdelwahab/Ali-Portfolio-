Title: Optimizing the thermal performance of a double-pipe heat exchanger using twisted tapes with variable cuts and Fe3O4 nanofluid
Authors: K.P.V. Krishna Varma; N.S. Naveen; P.S. Kishore; Satish Pujari; Krishna Jogi; V. Dhana Raju
Year 2024; Journal of Thermal Engineering 10(5):1184-1197; DOI 10.14744/thermal.0000860 (open access, Yildiz Tech Univ Press)
HX: double-pipe (twin-pipe: two copper inner tubes 17/19 mm, 5.6 m total, MS shell 60/63 mm), counter-flow; cut twisted tapes (twist ratio 3,5,7; cut radius 0,3,6)
Data: experimental. Fe3O4/water mono nanofluid 0.01, 0.03, 0.05 vol% in inner tube; hot water in annulus 0.1 kg/s constant, hot ~60 C (text typo "600 C"); inner flow 5/9/13 LPM (0.083-0.25 kg/s); Re not tabulated.
Design: Taguchi L9 orthogonal array (flow rate x vol% x cut radius) -> 9 runs in Table 5. ANN data size: not explicitly stated; appears to be the L9 data (9 points) -> Not reported explicitly.
ML: feed-forward BP ANN, MATLAB nntool, Levenberg-Marquardt, tansig hidden + linear output, 1 hidden layer, 10/20/30 neurons tried; 20 chosen by trial & error to minimize MSE.
Inputs: flow rate, vol% NP, cut radius. Outputs: h, Nu, ff, TPF (which output the ANN table refers to not stated).
Split: Not reported (MATLAB default train/val/test implied by Table 8 columns). No CV.
Metrics: Table 8 R values: 20 neurons -> training 1, validation 0.9999, testing 1, all 0.9992. No RMSE/MAE/MAPE.
Also Taguchi S/N + ANOVA regression (Minitab): flow rate contributes ~50% to h and Nu.
Uncertainty: experimental (Nu 1.64%, h_i 1.64%, U 1.47%). No model uncertainty.
Critical: ~9 samples with ~100 weights (3-20-1) -> extreme over-parameterization; R=1 on 1-2 test points is meaningless. Choosing neurons by min MSE incl. test = tuning on test.
Relevance: DPHE + nanofluid + experimental (high setup similarity) but ML methodology not usable; negative example.
Tier: 1 by scope (DPHE+exp+ML+nanofluid) but quality very low.
