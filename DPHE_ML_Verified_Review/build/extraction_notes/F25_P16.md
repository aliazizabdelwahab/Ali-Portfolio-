Title: Machine learning analysis of thermophysical and thermohydraulic properties in ethylene glycol- and glycerol-based SiO2 nanofluids
Authors: Suleiman Akilu; K.V. Sharma; Aklilu Tesfamichael Baheta; Praveen Kumar Kanti; Prabhu Paramasivam
Year 2024; Scientific Reports 14, 14829; DOI 10.1038/s41598-024-65411-8 (OA)
HX: single stainless tube (4.57/6.35 mm, L 1.0 m), constant heat flux split heaters - NOT DPHE.
Fluid: SiO2 nanofluids in glycerol (G) and ethylene glycol (EG), 0-1.0 vol%; measured k (KD2 Pro), mu, rho, cp 20-80 C (3 readings averaged).
Ranges: Re 1,300-21,000 (abstract) / up to 13,000 (text); experiments at 80 C.
Samples: Not reported. Inputs: "Reynolds and Prandtl numbers" (dataset description) - dimensionless; concentration implied via Pr. Output: Nu (models also mentioned for f).
Models: LR, DT, RF, XGBoost, AdaBoost (Python, Jupyter, pandas). Hyperparameters Not reported.
Split: random 70/30 train/test. No CV.
Metrics Nu (Table 4): LR test R2 0.35, MAPE 4.71%; DT train R2 1 (MSE 0) test R2 0.972 MAPE 0.908%; RF test R2 0.98 MAPE 0.714%; XGBoost test R2 0.9871, MSE 0.045, MAPE 0.585%; AdaBoost test R2 0.8725. Also Willmott index, Taylor diagram.
Abstract claims DT "performed well with few errors" while XGB has lower test error (inconsistent).
Uncertainty: property measurement uncertainty (k 2.4%, mu 4.1%); no predictive uncertainty.
Critical: test MAPE 0.6% < measurement uncertainty of properties -> suggests near-duplicate points across split; untransformed LR used as strawman (a log-linear Nu = c Re^m Pr^n power law would be the appropriate baseline - authors present that form but do not use it as ML baseline). DT with zero training error.
Strength: dimensionless inputs (Re, Pr); five-model comparison incl. linear baseline; Willmott/Taylor.
Tier 2 (tube; nanofluid; methodology moderately transferable).
